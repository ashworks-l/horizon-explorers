About Horizon Explorers

Discover the purpose and technology behind this web application.

🌍

Our Mission

Horizon Explorers helps travelers discover countries, learn interesting facts, organize trips, and save favorite destinations in one simple application.

💻

Technologies

HTML5, CSS3, Vanilla JavaScript, REST Countries API, Local Storage, Responsive Design and CSS Animations.

🚀

Features

Search countries, filter by region, save favorites, organize trips, create a wishlist and explore detailed destination information.
